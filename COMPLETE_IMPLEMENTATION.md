## 🚀 **Getting Started**

### **Prerequisites:**
- Node.js 18+ 
- npm or yarn
- OpenAI API key (for AI features)

### **Installation:**
```bash
cd /Users/ani/Downloads/demo
npm install
npm run dev
```

### **Environment Setup:**
Create `.env.local` with:
```
OPENAI_API_KEY=your_openai_api_key_here
```

### **Access the Application:**
- **Local Development**: http://localhost:3000
- **Login as Recruiter**: Use recruiter credentials
- **Login as Candidate**: Use candidate credentials
